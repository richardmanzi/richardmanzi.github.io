# ESP32 Community Examples — Sources & Attribution

These four independently authored GitHub projects are presented as **open-source learning references, not work built by Richard Manzi**. Each visible demo image is the authentic image in its source repository; the local WebP is only resized/re-encoded for the portfolio, with its content and aspect ratio preserved. The repositories declare MIT licenses; their full copyright and permission notices are copied into the portfolio and linked from the cards.

| Example / original author | Purpose, parts and connection notes | Original repository media | Code, build guide and license |
|---|---|---|---|
| **ESP32-C3 DHT11 serial monitor** — Sidharth Mohan Nair (`sidharthmohannair`) | Reads temperature/humidity from a DHT11 sensor and prints measurements to the Arduino Serial Monitor. Guide lists ESP32-C3 Super Mini, DHT11, breadboard, jumper wires and a 10 kΩ resistor; the sketch uses GPIO 10 for the sensor data pin. | Source screenshot: [result image](https://raw.githubusercontent.com/sidharthmohannair/Tutorial-ESP32-C3-Super-Mini/main/docs/examples/ESP32_C3_Super_Mini_with_DHT11/images/result_ESP32-C3_Super_Mini_with_DHT11.jpg). Local re-encode: [esp32-dht11-serial.webp](esp32/esp32-dht11-serial.webp). | [Repository](https://github.com/sidharthmohannair/Tutorial-ESP32-C3-Super-Mini) · [sketch](https://raw.githubusercontent.com/sidharthmohannair/Tutorial-ESP32-C3-Super-Mini/main/docs/examples/ESP32_C3_Super_Mini_with_DHT11/ESP32_C3_Super_Mini_with_DHT11.ino) · [wiring/setup guide](https://raw.githubusercontent.com/sidharthmohannair/Tutorial-ESP32-C3-Super-Mini/main/docs/examples/ESP32_C3_Super_Mini_with_DHT11/README.md) · [original MIT license](https://raw.githubusercontent.com/sidharthmohannair/Tutorial-ESP32-C3-Super-Mini/main/LICENSE) · [copied MIT notice](licenses/sidharth-tutorial-MIT.txt). The sketch’s source comments identify it as adapted from an Adafruit DHT example; see the original file for that note. |
| **ESP32-C3 DHT sensor web server** — Sidharth Mohan Nair (`sidharthmohannair`) | Reads DHT temperature/humidity values and serves them over Wi-Fi/HTTP from the ESP32-C3. The sketch uses GPIO 10 for the sensor. The source guide includes sensor, breadboard/wire, library and Wi-Fi setup information. | Source screenshot: [result image](https://raw.githubusercontent.com/sidharthmohannair/Tutorial-ESP32-C3-Super-Mini/main/docs/examples/ESP32_C3_Super_Mini_with_DHT11_webServer/images/result.png). Local re-encode: [esp32-dht11-web.webp](esp32/esp32-dht11-web.webp). | [Repository](https://github.com/sidharthmohannair/Tutorial-ESP32-C3-Super-Mini) · [sketch](https://raw.githubusercontent.com/sidharthmohannair/Tutorial-ESP32-C3-Super-Mini/main/docs/examples/ESP32_C3_Super_Mini_with_DHT11_webServer/ESP32_C3_Super_Mini_with_DHT11_webServer.ino) · [wiring/setup guide](https://raw.githubusercontent.com/sidharthmohannair/Tutorial-ESP32-C3-Super-Mini/main/docs/examples/ESP32_C3_Super_Mini_with_DHT11_webServer/README.md) · [original MIT license](https://raw.githubusercontent.com/sidharthmohannair/Tutorial-ESP32-C3-Super-Mini/main/LICENSE) · [copied MIT notice](licenses/sidharth-tutorial-MIT.txt). |
| **ESP32-S3 sound visualizer** — Andy Yu (`i4ucn`) | Uses an ESP32-S3 and INMP441 I²S digital microphone to display waveform, frequency-spectrum and sound-level data. Source wiring: VDD→3V3, GND→GND, SCK→GPIO5, WS→GPIO6, SD→GPIO4, L/R→GND. The detailed author guide is in Chinese. | Source demo image: [example.jpg](https://raw.githubusercontent.com/i4ucn/soundDance-esp32/main/images/example.jpg). Local re-encode: [esp32-sound-visualizer.webp](esp32/esp32-sound-visualizer.webp). | [Repository](https://github.com/i4ucn/soundDance-esp32) · [visualizer sketch](https://raw.githubusercontent.com/i4ucn/soundDance-esp32/main/arduino/02_sound_visualizer/02_sound_visualizer.ino) · [microphone serial-test sketch](https://raw.githubusercontent.com/i4ucn/soundDance-esp32/main/arduino/01_mic_serial_test/01_mic_serial_test.ino) · [build guide](https://i4ucn.github.io/soundDance-esp32/) · [original MIT license](https://raw.githubusercontent.com/i4ucn/soundDance-esp32/main/LICENSE) · [copied MIT notice](licenses/sounddance-esp32-MIT.txt). |
| **ESP32 WS2812B RGB-strip color cycle** — Tikita Tolley (`TikitaTolley`) | Cycles colors on a WS2812B addressable RGB strip with ESP32/FastLED. Parts named by the README: ESP32, WS2812B strip and USB-C data cable. For a stock board, the README says LED data→GPIO5 and strip power to 5V/GND; the photographed build uses the author's custom connector board. Setup: install FastLED, open `main.ino` in Arduino IDE, select the board and upload. | Source project photo: [led_blink_20260730.jpg](https://raw.githubusercontent.com/TikitaTolley/led-blink/main/media/led_blink_20260730.jpg). Local re-encode: [esp32-rgb-strip.webp](esp32/esp32-rgb-strip.webp). | [Repository](https://github.com/TikitaTolley/led-blink) · [sketch](https://raw.githubusercontent.com/TikitaTolley/led-blink/main/main/main.ino) · [materials/wiring/setup guide](https://raw.githubusercontent.com/TikitaTolley/led-blink/main/README.md) · [original MIT license](https://raw.githubusercontent.com/TikitaTolley/led-blink/main/LICENSE) · [copied MIT notice](licenses/tikita-led-blink-MIT.txt). |
